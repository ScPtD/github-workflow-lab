# GitHub Workflow Lab

Laboratório de documentação sobre pull requests, coautoria, Discussions e segurança de automações no GitHub.

## Transparência

Este laboratório é mantido por uma única pessoa, que utiliza contas próprias e assistência de IA. Exercícios entre essas contas demonstram recursos da plataforma; não representam colaboração entre pessoas distintas nem endossos independentes.

## Objetivo

Registrar a revisão de ferramentas de achievements e responder dúvidas reais sobre suas permissões, limitações e critérios. O conteúdo é documentação: nenhum script de terceiros é instalado ou executado aqui.

## Regras de trabalho

- Cada alteração deve acrescentar informação útil e verificável.
- Não publicar tokens, senhas, emails privados nem conteúdo de repositórios privados.
- Usar as ferramentas normais do GitHub e revisar o diff antes de mesclar.
- Não criar loops de PRs vazios, estrelas automáticas ou respostas duplicadas.
- Separar resultados observados de critérios estimados pela comunidade. A concessão de achievements depende do GitHub.
